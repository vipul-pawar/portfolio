SEC-01 // OVERVIEW

Overview

PicTale is a Django web application for managing a personal media library. Accounts are handled by Django's authentication system, and every photo or video in the library can be uploaded, edited and deleted — full CRUD, not just an upload form.

The interface is built with Tailwind CSS and ships with a responsive dark-mode UI, and the Django admin dashboard provides a management view over the content.

SEC-02 // PROBLEM & SOLUTION

Problem and solution

ISSUE
  • Media collections sprawl across folders and devices with no single place to manage them.
  • Upload-only galleries are frustrating: there is no way to correct or remove something once it is in.
  • A private library needs real accounts, not a link that anyone who has it can open.
APPROACH

Model the library properly in the Django ORM, tie every media item to its owner, and expose the full set of create, read, update and delete operations through authenticated views.

Use Django's admin dashboard for a management view, and Tailwind CSS to keep the interface readable on both light and dark screens.

SEC-03 // HOW IT WORKS

How it works

  1. 01 Sign in. User authentication guards the library — nothing is visible or editable without an account.
  2. 02 Upload. Photos and videos are submitted through the application's upload flow.
  3. 03 Store. The Django ORM records the item and its metadata, keeping ownership tied to the signed-in user.
  4. 04 Browse. The gallery renders the library in a responsive dark-mode interface.
  5. 05 Edit or delete. Every item can be updated or removed later — the full CRUD cycle, not just upload.
  6. 06 Administer. The admin dashboard gives a management view over users and media.

SEC-04 // KEY FEATURES

Key features

  • Full CRUD for photos and videos — create, view, edit and delete.
  • User authentication so the library stays private to its accounts.
  • Media upload, edit and delete flows built on Django views and the ORM.
  • Admin dashboard for managing content and users.
  • Responsive, dark-mode UI styled with Tailwind CSS.

SEC-07 // WHAT I LEARNED

What I learned

  • Model first: once the ORM models and relationships were right, the CRUD views became almost mechanical.
  • Authentication is a design decision, not an add-on — ownership has to be enforced in the views, not hidden in the interface.
  • Tailwind's dark-mode variants make a genuinely themeable interface possible without maintaining two separate stylesheets.
