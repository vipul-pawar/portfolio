SEC-01 // OVERVIEW

Overview

Two pneumatic cylinders have to work as a sequence rather than as two independent outputs: piston one runs its stroke and returns, and only once that cycle is genuinely over is piston two allowed to start.

The sequencing is handled entirely in ladder logic on a PLC, written in Siemens TIA Portal. A 5 second off-delay timer holds the hand-off condition, and negative edge detection marks the exact moment the first cylinder's cycle finishes.

The exercise covers both single-acting and double-acting cylinders, so the same logical sequence is applied to two different valve arrangements.

SEC-02 // PROBLEM & SOLUTION

Problem and solution

ISSUE
  • Actuating both pistons from the same start command overlaps their movements and breaks the intended sequence.
  • A level-triggered condition on the first cylinder re-fires the second step while piston one is still moving.
  • Without a defined hold window, the hand-off between the two actuators is unpredictable.
APPROACH

Use an off-delay (TOF) timer of 5 seconds on the first cylinder's cycle, and trigger the second piston on the negative edge — the moment the first cycle's condition drops away.

That combination makes the hand-off explicit: the second piston activates after the first completes its cycle, not while it is running.

SEC-03 // HOW IT WORKS

How it works

  1. 01 Start command. The operator input energises the first cylinder and starts its stroke.
  2. 02 Off-delay timing. A 5 second off-delay timer keeps the cycle condition alive for the full motion of piston one.
  3. 03 Negative edge detection. When the first cylinder's condition drops, the falling edge is latched as "cycle complete".
  4. 04 Second piston released. The latched edge is the only condition that starts piston two, so it cannot begin early.
  5. 05 Return and reset. The sequence ends with both actuators back in their home positions and the logic ready for the next start.

SEC-04 // KEY FEATURES

Key features

  • 5 second off-delay timer governing the hand-off between the two cylinders.
  • Negative (falling) edge detection to identify the end of the first cycle.
  • Interlocked sequence: the second piston has exactly one valid start condition.
  • Covers both single-acting and double-acting cylinder behaviour in one program.
  • Written and documented as ladder logic in Siemens TIA Portal.

SEC-07 // WHAT I LEARNED

What I learned

  • Edge detection versus level detection — a level condition keeps re-triggering a step, while a falling edge marks a single, unambiguous event.
  • An off-delay timer is the right tool for holding a hand-off window after an input drops; picking the wrong timer type changes the whole sequence.
  • The same logical sequence is wired differently depending on whether a cylinder is single- or double-acting.
